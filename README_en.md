# TRM Cloud-Native Intelligent Development & Operations Platform

[中文](README.md) | [English](README_en.md)


![TRM Cloud-Native Cluster Console](./does/img.png)

**TRM Cloud-Native Intelligent Development & Operations Platform** is a front-end console designed for Kubernetes multi-cluster, edge cloud, AIOps, and FinOps scenarios.

## Features

- **Cluster Management**: Cluster overview, cluster listing, cluster addition, health inspection, version upgrade
- **Node Management**: Node list, node pools, node maintenance
- **Smart Edge Cloud**: Edge sites, device access, edge networking
- **Application Workloads**: Deployments, Service / Ingress, GitOps delivery
- **CICD**: CI / GitLab, CD / Argo CD, pipeline templates, artifact management
- **AIOPS Intelligent Operations**: Observability, root cause analysis, automated governance, elastic vertical scaling
- **FinOps Cost Governance**: Cost overview, cost allocation, resource optimization, budget alerts
- **Alert Center**: Alert rules, alert events, notification channels
- **System Settings**: Permission management, audit logs, platform integration
